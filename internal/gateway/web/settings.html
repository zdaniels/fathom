Features

Shell execution
Let the agent run shell commands (tests, git, builds). The single biggest security surface — off by default.
Sub-agents
Allow the agent to delegate scoped tasks to child agents. restart to apply
Swarms
Enable the swarm tool — multiple role-agents collaborating on a shared blackboard over rounds. restart to apply
Claude Code
Let the agent hand coding tasks to the local Claude Code CLI (uses your Claude subscription login — no API key). It can read/write files in the workspace. restart to apply
Web search
Allow the web-search tool to reach DuckDuckGo. Adds a network allow-rule for its domains.

Model

Default model
The model used when the router doesn't pick a profile-specific one. restart to apply

Takeover

Takeover mode
Route every message straight to an external coding agent instead of the local agent — you're chatting with that agent through Fathom, each thread kept as one session. restart to apply
Provider
Which CLI handles takeover: Claude Code (your Claude subscription) or OpenAI Codex (your ChatGPT login). restart to apply
